# 📚 Book Recommender System

A machine learning–based **Book Recommender System** that suggests books based on popularity and similarity.

---

## 🔍 Project Overview

This project provides two main features:

### 1️⃣ Top 50 Books  
- Displays the **Top 50 most popular books**
- Ranked based on **number of reviews and ratings**

### 2️⃣ Book Recommendation System  
- Users can **search for a book**
- The system recommends **5 similar books**
- Uses **content-based filtering** for recommendations

---

## ⚙️ Tech Stack

- **Language:** Python  
- **Libraries:** NumPy, Pandas, Scikit-learn  
- **Web Framework:** Flask  
- **Frontend:** HTML, CSS  
- **Version Control:** Git, GitHub  

---

## 🧠 Working Methodology

- Data cleaning and preprocessing using Pandas  
- Popularity-based recommendation for Top 50 books  
- Similarity calculated using **Cosine Similarity**  
- Content-based recommendation model  

---

## 🚀 Features

- ✔ Displays Top 50 popular books  
- ✔ Search-based book recommendations  
- ✔ User-friendly interface  
- ✔ Fast and accurate suggestions
